# 简历书写 Skill

v1.0.0 · Betty（小鹿） · [MIT 许可证](LICENSE)

面向在校生和应届生，帮助把课程、实习和项目经历写成适合目标岗位的简历。可处理新简历、旧简历定向改写和单栏微调。

## 使用方式

将整个 resume-writing-skill 文件夹交给支持本地 Skill 的 Codex 安装。使用时附上已隐去身份信息的简历或经历，以及目标岗位原文或意向方向。

> 用 $resume-writing-skill，按这份岗位描述帮我改简历。请保留能说明我实际贡献的事实，并指出哪几条还需要我核实。

可从[虚构课程项目示例](references/课程项目改写示例.md)开始。本版已核对文件结构与示例，安装后的完整使用流程待实际试用。
